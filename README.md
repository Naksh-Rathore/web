# Cybersecurity Portfolio - Anmol Sharma

## Overview
This repository contains the source code for my, Anmol Sharma's professional cybersecurity portfolio website. The website showcases my skills, projects, experience, and contact information in an interactive and visually appealing format.

## Features

### Technical Features
- **Interactive 3D Background**: Uses Vanta.js NET animation for a dynamic visual experience
- **Matrix Rain Effect**: Custom JavaScript implementation of the classic matrix code rain
- **Responsive Design**: Fully responsive layout that works on all device sizes
- **Smooth Animations**: Includes scroll animations and typing effects
- **Modern UI**: Clean, dark-themed interface with cyberpunk aesthetics
- **Form Submission**: Functional contact form with email integration

### Content Sections
1. **Hero Section**: Glitch-text animated introduction
2. **About Me**: Professional summary and personal background
3. **Skills**: Interactive progress bars for technical and soft skills
4. **Projects**: Grid layout showcasing key projects
5. **Experience**: Timeline visualization of professional experience
6. **Contact**: Contact form and information

## Technologies Used

### Frontend
- HTML5, CSS3, JavaScript
- Tailwind CSS for styling
- Three.js and Vanta.js for 3D background effects
- AOS (Animate On Scroll) library for scroll animations
- Font Awesome for icons

### Design Elements
- Cyberpunk/tech aesthetic with glitch effects
- Terminal/command-line inspired UI elements
- Gradient accents and neon highlights
- Custom matrix rain animation

## Installation & Usage

### Local Development
1. Clone the repository:
   ```
   git clone https://github.com/gostmennnnn/web.git
   ```

2. Open `code/index.html` in any browser, and the website will show!
